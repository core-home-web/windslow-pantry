# Web fonts

These open-source fonts stand in for the licensed brand typefaces on the website.

| File | Family | License |
| --- | --- | --- |
| `playfair-*.woff2` | Playfair Display (stand-in for Begum Bold) | SIL Open Font License 1.1 |
| `yellowtail-*.woff2` | Yellowtail (stand-in for Quimby Mayoral) | Apache License 2.0 |
| `instrument-sans-*.woff2` | Instrument Sans (body text) | SIL Open Font License 1.1 |

Files are the Latin and Latin Extended subsets served by Google Fonts.
